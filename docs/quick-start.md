# Quick start

Make your first game with an AI helper in about 1 hour. The full guide starts at [1-setup.md](1-setup.md).

## 1. Get an AI helper
Use a desktop or laptop computer (Windows, Mac, or Linux). Install **one** helper:

| Helper | Get it | Plan |
|---|---|---|
| **Claude Code** | [claude.com/download](https://claude.com/download) (open the **Code** tab) | Claude Pro or higher |
| **ChatGPT Codex** | [chatgpt.com/codex](https://chatgpt.com/codex) (the desktop app) | ChatGPT Plus or higher |

For a kid, use the parent's account (18+). On Windows, also install [Git for Windows](https://git-scm.com/downloads/win).

## 2. Paste the prompt
1. Make a new, empty folder, for example `my-game`.
2. Open the helper in that folder.
3. Paste the prompt from the [README](../README.md#try-it-yourself).
4. The helper asks before each install. Say yes or no.

## 3. How you work together
1. You say what you want, in plain words.
2. The helper shows a plan and asks you 1–3 questions about it.
3. A wrong answer gets a hint, not the answer.
4. Nothing changes until you say yes.
5. The helper does one small step. You press **F5** in Godot and play.

## 4. What to say

| Say | What happens |
|---|---|
| `ok` | Keep it, go to the next step |
| a tweak, like "jump higher" | One small change |
| `idea: …` | A new feature, with a plan first |
| `bug: …` | The helper finds the cause and fixes only that |
| `?` | The helper explains the last step |
| `undo` | The last step goes away |

All keywords are in `SKILLS.md` in your game folder.
